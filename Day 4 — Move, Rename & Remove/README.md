# Day 4 — Move, Rename & Remove

## Commands Practiced

```bash
mv notes.txt archive/                    # Move file to archive

mv draft.txt final_notes.txt            # Rename file

mv New-Project Linux-Project            # Rename directory

mv notes.txt Linux-Project/notes.txt    # Move file into project folder

mv -i notes.txt archive/                # Ask before overwrite

mv -v notes.txt archive/                # Show moving process

rm temp.txt                            # Delete a file

rm -i temp.txt                         # Ask before deleting

rm -r Linux-Project/                   # Delete directory recursively

rm -rf Linux-Project/                  # Force delete directory
```

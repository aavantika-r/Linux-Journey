### Directories Learned
- `/home` — User files
- `/root` — Root user's home
- `/etc` — Configuration files
- `/var` — Frequently changing data
- `/tmp` — Temporary files
- `/usr` — Programs, libraries, documentation
- `/boot` — Boot process files
- `/dev` — Device files
- `/proc` — Process & running kernel info
- `/sys` — Kernel & hardware info
- `/opt` — Optional software
- `/mnt` — Temporary mount point
- `/media` — USB/removable media
- `/bin` — User commands
- `/sbin` — System administration commands

## Commands Practiced

```bash
pwd              # Show current directory
ls               # List files & directories
ls -l            # Long listing format
ls -a            # Show hidden files
ls -la           # Long + hidden files
ls -lh           # Long + human readable files
ls -R            # List Recursively

mkdir devops     # Create a directory
mkdir linux
mkdir git
mkdir devops linux  # multiple directory creation
mkdir -p devops/linux/git   # Create nested directories

cd devops        # Enter devops
cd ..            # Go to parent directory
cd ~             # Go to home directory
cd /             # Go to root directory
```
